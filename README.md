# SACE Ascent

You are a senior product designer, UX architect, creative director, frontend engineer, animation expert, accessibility specialist and conversion optimization expert.

Your task is to design and build a world-class website for SACE (South Australian College of English).

IMPORTANT:

this is there current website : https://sace.edu.au/

DO NOT redesign the brand.

DO NOT change the brand identity.

KEEP the existing SACE logo.

KEEP the existing SACE colour palette.

The goal is to modernize the digital experience while preserving the institutional trust and recognition that SACE has built over the years.

This is NOT a template website.

This should feel like one of the best education websites in Australia.

The quality should be comparable to Apple, Stripe, Airbnb, Notion, Harvard, and modern university websites.
